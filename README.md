# Городской портал на PHP + MySQL

Независимое городское издание: новости, афиша, кино, радио, погода и админ-панель.
**Без рекламы, без аналитики, без cookie и без сбора данных о читателях** (см. `docs/PRIVACY.md`). Преобразовано из статического сайта; весь контент перенесён в базу данных.

**Окружение:** PHP 8.2+ (рекомендуется 8.4/8.5: 8.1 снят с поддержки, 8.2 — только до 31.12.2026), MySQL 8.4+ или MariaDB 10.11+ (старые ветки сняты с поддержки). Composer и Node.js **не нужны**. Установщик **ничего не блокирует**: проверки сервера — лишь подсказки (нет GD — нельзя загружать фото, нет WebP — фото делаются в JPEG/PNG, нет curl — не работают погода и IndexNow; всё остальное работает). Если `config/` недоступна для записи, установщик покажет готовый `config.php` для ручного сохранения.

## Установка

Загрузите содержимое архива на хостинг так, чтобы **корнем сайта была папка `public/`**. Если изменить корень нельзя — оставьте всё как есть: корневой `.htaccess` перенаправит запросы в `public/` и закроет служебные папки.

### Способ 1. Мастер установки (проще всего)
1. Создайте пустую БД (utf8mb4) и пользователя в панели хостинга или phpMyAdmin.
2. Откройте сайт в браузере — запустится мастер. Введите данные БД, адрес сайта, логин и пароль администратора (от 10 символов).
3. Мастер создаст таблицы, загрузит 11 статей, рубрики, теги, ссылки, страницы «О редакции», «Контакты», «Редакционные принципы», SEO-файлы, ключ IndexNow и `config/config.php`.

### Способ 2. Через phpMyAdmin
1. Импортируйте `database/schema.sql`, затем `database/seed.sql` (вкладка «Импорт», кодировка utf8mb4).
2. Скопируйте `config/config.sample.php` в `config/config.php`, заполните БД, `app.url`, `app.key` (64 случайных hex-символа). Файл `installed.lock` не нужен: сайт считается установленным, когда есть `config.php`.
3. Создайте администратора вставкой строки в `users` (роль `admin`; хэш: `php -r 'echo password_hash("пароль", PASSWORD_ARGON2ID);'`) и страницы: `php -r 'require "app/bootstrap.php"; echo App\Support\BasePages::install();'`. Проще Способ 1 — он делает всё сам.

### Способ 3. Консоль
```
DB_NAME=tk DB_USER=tk DB_PASS=... SITE_URL=https://example.ru ADMIN_USER=admin \
ADMIN_EMAIL=me@example.ru ADMIN_PASS='длинный-пароль' CONTACT_EMAIL=redakciya@example.ru php bin/install.php
```

### После установки
1. «Настройки → Сайт и редакция»: e-mail редакции (он показывается на «Контактах»), название издателя.
2. «Настройки → SEO»: коды Яндекс.Вебмастера/Google. Желательно включить 2FA («Профиль»).
3. cron (необязательно, но надёжнее): `*/5 * * * * php /путь/bin/cron.php` и `0 3 * * * php /путь/bin/backup.php`.
4. Чек-лист развёртывания — `docs/SECURITY-AUDIT.md`, раздел 4.

## Настройка под свой город и издание (всё — из админки, без правки кода)
* **Меню сайта** («Сайт → Меню сайта»): переименовать, переставить, **создать**, **удалить** и **отключить** пункты. Разделы Новости/Афиша/Кино/Погода/Радио нельзя удалить, но можно отключить: пункт исчезает из шапки и подвала, адрес отвечает «страница не найдена», раздел выпадает из sitemap. Пункт может вести на страницу из раздела «Страницы» или на любую ссылку.
* **Оформление и бренд** («Настройки»): логотип (шапка и подвал), фавикон — из одной квадратной картинки автоматически создаются `favicon.ico`, значок iOS/Android и PWA-иконки, фирменный цвет (шапка, кнопки; проверяется контраст), картинка для соцсетей по умолчанию, короткое название приложения.
* **Сайт и редакция:** название, слоган, описание, город в трёх падежах (для заголовков и описаний), регион, контакты, издатель, кинотеатр.
* **Погода — WeatherAPI.com:** ключ создаётся бесплатно на weatherapi.com и вводится в «Настройки → Радио, погода, кино»; сервер запрашивает прогноз не чаще раза в 30 минут (браузер читателя к WeatherAPI не обращается). Число дней прогноза (1–14) зависит от тарифа: бесплатный даёт 3. Без ключа блок погоды скрыт. Ключ от старого Open-Meteo не подойдёт — введите новый.
* **Обновление существующего сайта:** просто замените файлы — недостающую таблицу `menu_items` сайт создаст сам при первом запросе (`app/Support/Migrator.php`).

## Читателю
* **Радио играет при переходах по сайту** (страница при этом не перезагружается, поэтому ссылка «открыть в двух вкладках» больше не нужна). Страницы подгружаются «плавно» (шапка и плеер не перезагружаются), работают кнопки «Назад/Вперёд», поиск и закладки. Эфир переподключается при обрыве, управляется с экрана блокировки (Media Session). Ограничение: полная перезагрузка (F5) или переход на чужой сайт в этой же вкладке остановит эфир — внешние ссылки поэтому открываются в новой вкладке.
* **Тема оформления:** кнопка в шапке — «как в системе» → светлая → тёмная; выбор запоминается в браузере (localStorage, без cookie) и применяется до отрисовки страницы. Есть и в админке.
* Mobile-first вёрстка (проверена автотестом на 15 ширинах от 320 до 1920 px × 12 страниц — без горизонтальной прокрутки), `prefers-reduced-motion`, фокус с клавиатуры, skip-link, контраст WCAG AA, шрифты локально, WebP с `srcset`.

## SEO — полная автоматизация
Всё обновляется само при сохранении/публикации/удалении материала:
* `sitemap.xml` (индекс) + страницы, новости с картинками, афиша, **Google News**; `robots.txt` (с `Clean-param` для Яндекса, опция запрета ИИ-ботов, режим «закрыто от индексации»); `rss.xml`; `rss-yandex.xml` (Яндекс Новости/Дзен); `llms.txt`; `manifest.webmanifest`; `opensearch.xml`; `.well-known/security.txt`; ключ **IndexNow**.
* Файлы подтверждения Яндекс.Вебмастера и Google создаются по коду из настроек — без FTP.
* **IndexNow**: мгновенное уведомление Яндекса и Bing о новом/изменённом/удалённом адресе (Google IndexNow не поддерживает — ему нужен sitemap, отправьте его в Search Console один раз).
* JSON-LD: NewsMediaOrganization, WebSite+SearchAction, NewsArticle, BreadcrumbList, CollectionPage/ItemList, Event, RadioStation; Open Graph, Twitter Cards, canonical, prev/next.
* Автокартинка 1200×630 для превью, если у новости нет фото; авто-описание и лид; 304 Not Modified для краулеров.
* **301-редиректы** со всех старых адресов; при смене адреса новости — автоматический 301; при удалении — 410; мастер редиректов и журнал 404.
* SEO-центр: готовность к индексации, аудит материалов, журнал IndexNow; в редакторе — предпросмотр сниппета и живой чек-лист.

## Админ-панель
Новости (черновик → проверка → публикация, планирование, закрепление, теги, галерея), афиша, страницы, рубрики, **медиатека** (WebP/JPEG-варианты, drag&drop, **защита от дублей** по содержимому файла, корректные пропорции), ссылки/сервисы главной, редиректы, 404, настройки, пользователи и роли, профиль (пароль, 2FA, сеансы), журнал действий, резервные копии БД, проверка безопасности сервера, тёмная тема.

## Безопасность (кратко)
Argon2id, блокировка перебора, 2FA TOTP + резервные коды, сессии в БД (ID — хэш), CSRF, строгий CSP **без единого стороннего источника** (кроме потока радио), HSTS, белый список HTML, безопасная загрузка с перекодированием, запрет исполнения в `uploads/`, подготовленные запросы, шифрование секретов (AES-256-GCM), журнал действий. Отчёт (актуальный на 8.10.2026) — `docs/SECURITY-AUDIT.md`.

## Тесты (на тестовом экземпляре, не на боевом сайте)
```
python3 tools/security_tests.py        # 69 проверок: заголовки, CSRF, XSS, SQLi, обход пути, загрузка файлов, роли, приватность
python3 tools/security_tests_2fa.py    # 2FA и TOTP по вектору RFC 6238
python3 tools/browser_tests.py         # 33 проверки в браузере: радио при переходах, тема, нет внешних запросов, Медиатека
python3 tools/layout_sweep.py          # адаптивность: 15 ширин × 12 страниц
```

## Переезд со старого сайта
`python3 tools/migrate_static.py /путь/к/старому/сайту` — повторно соберёт seed. Старые URL перенаправляются автоматически (`/advertising.html` и `/advertisements.html` ведут на главную). Фото первой новости было ссылкой на korvesti.ru — загрузите своё; часть текстов, вероятно, заимствована из других изданий — проверьте права и указывайте источник.
