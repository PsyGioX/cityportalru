# Установка

## Требования

| | Минимум | Рекомендуется (на октябрь 2026) |
|---|---|---|
| PHP | 8.2 (получает только исправления безопасности до 31.12.2026) | **8.4 или 8.5** |
| База данных | MariaDB 10.11 / MySQL 8.4 | MariaDB 11.4 LTS, MySQL 8.4 LTS |
| Расширения PHP | `pdo_mysql`, `mbstring`, `dom`, `openssl`, `fileinfo` | + `gd` (фото, иконки), `curl` (погода, IndexNow), `exif` |
| Сервер | Apache (mod_rewrite) или nginx + php-fpm | HTTPS обязателен |

Composer и Node.js не нужны. Установщик ничего не блокирует: проверки — подсказки.

## Способ 1. Мастер в браузере (рекомендуется)

1. Загрузите файлы проекта. **Корнем сайта сделайте папку `public/`** (в панели хостинга: «Корневая папка сайта»). Если сменить корень нельзя — в корне лежит запасной `.htaccess`, закрывающий служебные папки.
2. В панели хостинга создайте пустую базу (utf8mb4) и пользователя с правами на неё.
3. Откройте сайт — запустится мастер. Он состоит из шести шагов:
   1. **Проверка сервера** — версии PHP/расширений, права на запись, HTTPS.
   2. **База данных** — кнопка «Проверить подключение» ничего не устанавливает, но сразу покажет: неверный пароль, нет базы, нет прав `CREATE`, версия СУБД снята с поддержки.
   3. **Сайт и город** — название, адрес, адрес админки (есть кнопка «Случайный»), город в трёх падежах, регион, координаты, часовой пояс, ключ WeatherAPI.
   4. **Набор данных** — «Чистый сайт», «Данные города Кореновск» или «Кореновск + демо-материалы».
   5. **Администратор** — есть генератор надёжного пароля.
   6. **Издание** — издатель и публичный e-mail (можно позже).
4. После установки войдите в админку и пройдите список «Что сделать дальше» на экране завершения.

Если `config/` недоступна для записи, мастер покажет готовый текст `config/config.php` — сохраните его вручную.

## Способ 2. Консоль

```bash
DB_NAME=tk DB_USER=tk DB_PASS='пароль' SITE_URL=https://example.ru \
ADMIN_USER=admin ADMIN_EMAIL=me@example.ru ADMIN_PASS='длинный-пароль-12+' \
PROFILE=empty SITE_NAME='Новости Города' CITY_NAME=Город CITY_NAME_IN='в Городе' CITY_NAME_OF=Города \
CITY_LAT=55.75 CITY_LON=37.62 TZ=Europe/Moscow WEATHER_KEY=ваш_ключ \
php bin/install.php
```

`PROFILE`: `empty` · `korenovsk` · `demo`. Без `PROFILE` берётся `korenovsk`.

## Способ 3. Вручную через phpMyAdmin

1. Импортируйте `database/schema.sql`.
2. Для Кореновска дополнительно `database/korenovsk.sql`; демо-статьи — `database/seed.sql` (до `korenovsk.sql`).
3. Скопируйте `config/config.sample.php` в `config/config.php`, заполните. Администратора создайте мастером в консоли или SQL-вставкой с хэшем Argon2id (`password_hash`).

## Профили данных

| Профиль | Что внутри |
|---|---|
| `empty` | Таблицы, меню, страницы «О редакции», «Контакты», «Принципы». Ничего о Кореновске: подходит для любого города |
| `korenovsk` | `empty` + `database/korenovsk.sql`: падежи и координаты города, рубрики, страницы «О Кореновске» и «Экстренные службы», ссылки на сайты администраций |
| `demo` | `korenovsk` + `database/seed.sql`: 11 статей, фото, ссылки сервисов |

`database/korenovsk.sql` можно запускать и на готовом сайте повторно: он обновляет только настройки города, а рубрики/страницы/ссылки добавляет, лишь если их ещё нет. Факты о городе взяты из открытых источников; прежде чем публиковать, проверьте их.

## Защита после установки

* `noindex` на локальных адресах включается автоматически; на боевом проверьте «Настройки → SEO».
* Включите 2FA, не оставляйте адрес админки `admin`.
* Установщик отключается сам: при наличии `config/config.php` он больше не запускается.
* Cron: `*/5 * * * * php /путь/bin/cron.php`.
