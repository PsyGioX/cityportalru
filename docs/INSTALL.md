# Установка

Ниже самое важное. Если нужны подробности, откройте раздел «Установка подробно» в [README](../README.md).

## Что понадобится

| | Минимум | Лучше (на октябрь 2026) |
|---|---|---|
| PHP | 8.2 (исправления безопасности — до 31.12.2026) | **8.4 или 8.5** |
| База данных | MariaDB 10.11 или MySQL 8.4 | MariaDB 11.4 LTS, MySQL 8.4 LTS |
| Расширения PHP | `pdo_mysql`, `mbstring`, `dom`, `openssl`, `fileinfo` | ещё `gd` (фото, иконки), `curl` (погода, IndexNow), `exif` |
| Сервер | Apache (mod_rewrite) или nginx + php-fpm | HTTPS обязателен |

Composer и Node.js не нужны. Установщик ничего не запрещает: все проверки — просто подсказки.

## Способ 1. Мастер в браузере (проще всего)

1. Загрузите файлы на сервер. **Корнем сайта сделайте папку `public/`** (в панели хостинга это «Корневая папка сайта»). Если поменять корень нельзя, не страшно: запасной `.htaccess` закроет служебные папки.
2. Создайте пустую базу в кодировке utf8mb4 и пользователя с правами на неё.
3. Откройте сайт. Запустится мастер из шести шагов:
   1. **Проверка сервера**: версии, права на запись, HTTPS.
   2. **База данных**: кнопка «Проверить подключение» ничего не ставит, но сразу покажет, что не так (пароль, база, права `CREATE`, старая версия СУБД).
   3. **Сайт и город**: название, адрес, адрес админки (кнопка «Случайный» придумает неочевидный), город в трёх падежах, регион, координаты, часовой пояс, ключ WeatherAPI.
   4. **Набор данных**: чистый сайт, данные Кореновска или Кореновск с демо-материалами.
   5. **Администратор**: есть генератор надёжного пароля.
   6. **Издание**: издатель и публичный e-mail (можно заполнить позже).
4. Войдите в админку и пройдите список «Что сделать дальше» на последнем экране.

Если папка `config/` недоступна для записи, мастер покажет готовый текст `config/config.php`: сохраните его вручную.

## Способ 2. Консоль

Подойдёт для VPS и автоматизации:

```bash
DB_NAME=tk DB_USER=tk DB_PASS='пароль' SITE_URL=https://example.ru \
ADMIN_USER=admin ADMIN_EMAIL=me@example.ru ADMIN_PASS='длинный-пароль-12+' \
PROFILE=empty SITE_NAME='Новости Города' CITY_NAME=Город CITY_NAME_IN='в Городе' CITY_NAME_OF=Города \
CITY_LAT=55.75 CITY_LON=37.62 TZ=Europe/Moscow WEATHER_KEY=ваш_ключ \
php bin/install.php
```

`PROFILE` бывает `empty`, `korenovsk` или `demo`. Если его не указать, возьмётся `korenovsk`.

## Способ 3. Вручную через phpMyAdmin

1. Импортируйте `database/schema.sql`.
2. Для Кореновска добавьте `database/korenovsk.sql`; демо-статьи лежат в `database/seed.sql` (импортируйте его до `korenovsk.sql`).
3. Скопируйте `config/config.sample.php` в `config/config.php` и заполните. Администратора создайте консольным мастером или вставкой в таблицу `users` с хэшем Argon2id (`password_hash`).
4. Откройте любую страницу сайта: недостающие таблицы и черновики политик создадутся сами.

## Профили данных

| Профиль | Что внутри |
|---|---|
| `empty` | Таблицы, меню, страницы «О редакции», «Контакты», «Принципы». Ничего о Кореновске, подходит для любого города |
| `korenovsk` | `empty` плюс падежи и координаты города, рубрики, страницы «О Кореновске» и «Экстренные службы», ссылки на сайты администраций |
| `demo` | `korenovsk` плюс 11 статей с фото и ссылки сервисов |

`database/korenovsk.sql` можно запускать и на готовом сайте: он обновит только настройки города, а рубрики, страницы и ссылки добавит, если их ещё нет. Факты о городе взяты из открытых источников, перед публикацией проверьте их.

## После установки

* На локальных адресах `noindex` включается сам; на боевом сайте проверьте «Настройки → SEO».
* Включите 2FA и не оставляйте адрес админки `admin`.
* Настройте cron: `*/5 * * * * php /путь/bin/cron.php`.
* Если планируете счётчик или рекламу, прочитайте [про cookie и согласие](COOKIES.md). Без них ничего делать не нужно.
* Мастер отключается сам: пока есть `config/config.php`, он не запускается.
