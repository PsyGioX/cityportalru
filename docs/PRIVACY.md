# Приватность: что сайт знает о читателях — ничего

«Твой Кореновск» построен как **независимое издание без рекламы и без сбора данных**. Это архитектурное решение, а не формальность: данных нет, поэтому нечего защищать, раскрывать и согласовывать.

## Чего на сайте нет
| | |
|---|---|
| Реклама, баннеры, партнёрские метки | удалены полностью (код, таблицы, админ-раздел, адреса) |
| Аналитика и счётчики (Яндекс Метрика, Google Analytics и т.п.) | нет |
| Cookie для читателей | **не выдаются** (проверяется автотестом) |
| Формы с персональными данными (обратная связь, объявления, заявки) | удалены; связь — по e-mail, который читатель пишет сам |
| Сторонние встраиваемые виджеты, шрифты, скрипты, картинки | нет: всё отдаётся с вашего домена; CSP запрещает чужие источники |
| Запись IP, User-Agent, referrer читателей в БД и журналы приложения | нет |
| Профили, идентификаторы, «отпечатки» браузера | нет |
| Капча и антиспам-сервисы | не нужны — нечего защищать |

## Что есть
* **Общий счётчик просмотров** под материалом: число без привязки к человеку (боты по User-Agent не считаются, сам User-Agent не сохраняется).
* **Выбор темы оформления** хранится в `localStorage` браузера читателя (не cookie, на сервер не уходит).
* **Радио** загружает аудиопоток с сервера радиостанции только после нажатия «слушать» — это явное действие читателя; радиостанция, как любой сервер потокового вещания, видит IP слушателя.
* **Погоду** запрашивает у WeatherAPI.com сервер сайта, а не браузер читателя.
* Ссылки на госуслуги, доставку, кинотеатр, соцсети — обычные ссылки: данные уходят туда, только если читатель сам по ним перешёл.

## Данные редакции (единственные персональные данные в системе)
Учётные записи сотрудников (логин, e-mail, хэш пароля), журнал действий и попыток входа (с IP — для защиты от взлома, хранятся 7 дней/в журнале действий), сессии админки (cookie только у вошедших сотрудников).

## Важно
* Хостинг-провайдер и веб-сервер ведут собственные журналы доступа (IP, время, адрес). Это вне приложения: при желании отключите/анонимизируйте access-логи в настройках сервера (в Nginx — `access_log off;` или сокращение IP).
* Отказ от сбора данных упрощает, но не отменяет требования закона: например, законы о СМИ, авторском праве, знаках информационной продукции и о материалах, запрещённых к распространению, действуют независимо. Проверьте, что применимо к вашему изданию (в «Настройки → Сайт и редакция» есть необязательные поля «Регистрация СМИ» и «Знак возрастной категории»).
* Если позже добавите форму, аналитику или рекламу — вернутся и обязанности по персональным данным (уведомление в Роскомнадзор, политика, согласие, cookie-баннер для ЕС). Эти компоненты намеренно не включены.
