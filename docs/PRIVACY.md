# Приватность: что сайт знает о читателях

Коротко: по умолчанию ничего. «Твой Кореновск» задуман как независимое издание без рекламы и без слежки. Раз данных нет, их не нужно защищать, раскрывать и согласовывать. Если вы всё же решите подключить аналитику, для этого есть отдельный, аккуратный путь: [cookie-баннер и согласие](COOKIES.md).

## Чего на сайте нет

| | |
|---|---|
| Реклама, баннеры, партнёрские метки | Удалены полностью (код, таблицы, админ-раздел, адреса) |
| Аналитика и счётчики | Нет, пока вы сами не включили Яндекс Метрику в настройках |
| Cookie для читателей | Не выдаются (проверяется автотестом) |
| Формы с персональными данными (обратная связь, объявления, заявки) | Удалены; связь по e-mail, который читатель пишет сам |
| Сторонние виджеты, шрифты, скрипты, картинки | Нет: всё отдаётся с вашего домена, CSP запрещает чужие источники |
| Запись IP, User-Agent и referrer читателей в базу и журналы | Нет |
| Профили, идентификаторы, «отпечатки» браузера | Нет |
| Капча и антиспам-сервисы | Не нужны: защищать нечего |

## Что есть

* **Счётчик просмотров** под материалом: просто число, без привязки к человеку. Боты по User-Agent не считаются, сам User-Agent не сохраняется.
* **Тема оформления** хранится в `localStorage` браузера (это не cookie, на сервер она не уходит).
* **Радио** загружает аудиопоток только после нажатия «слушать». Радиостанция, как любой сервер вещания, видит IP слушателя.
* **Погоду** у WeatherAPI.com запрашивает сервер сайта, а не браузер читателя.
* **Ссылки** на госуслуги, доставку, кинотеатр и соцсети обычные: данные уходят туда, только если читатель сам перешёл по ссылке.

## Если включить cookie-баннер

Когда вы включаете баннер (и тем более Яндекс Метрику), картина немного меняется, и это стоит знать:

* Выбор читателя хранится в `localStorage` под ключом `tk-consent`: случайный идентификатор, выбор, версия текста, время.
* На сервер уходит короткая запись для журнала согласий: те же поля без IP и браузера. Хранится 3 года.
* Яндекс Метрика загружается только после согласия и получает то, что получает любой счётчик: идентификатор браузера, адреса просмотренных страниц, сведения об устройстве.
* Адреса `mc.yandex.ru` и `yastatic.net` появляются в политике безопасности (CSP).
* Фраза в подвале «без cookie» перестаёт быть правдой. Её нужно изменить.

## Данные редакции

Единственные персональные данные в системе по умолчанию: учётные записи сотрудников (логин, e-mail, хэш пароля), журнал действий и попыток входа (с IP, для защиты от взлома, попытки входа хранятся 7 дней), сессии админки. Cookie `tksid` выдаётся только тем, кто вошёл в админку.

## Что важно помнить

* Хостинг-провайдер и веб-сервер ведут свои журналы доступа (IP, время, адрес). Это вне приложения. Если хотите, отключите или обезличьте их в настройках сервера (в nginx — `access_log off;`).
* Отсутствие сбора данных не отменяет остальные законы: о СМИ, об авторском праве, о знаках информационной продукции, о запрещённых материалах. В «Настройки → Сайт и редакция» есть необязательные поля «Регистрация СМИ» и «Знак возрастной категории».
* Если добавите форму, комментарии или рекламу, вернутся и обязанности по персональным данным: уведомление в Роскомнадзор, политика, отдельное согласие. Этих компонентов в движке нет намеренно.
