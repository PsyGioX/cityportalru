# Обновление

Обычно всё просто: заменить файлы и открыть любую страницу. Таблицы и настройки новых версий создаёт `Migrator`, SQL вручную выполнять не нужно.

## Общий порядок (для любой версии)

1. **Сделайте копию**: «Система → Создать копию» и копию папки `public/uploads/`.
2. Замените файлы проекта новыми. **Не затирайте** `config/config.php` и `public/uploads/`.
3. Откройте любую страницу сайта. `Migrator` сам доведёт базу до нужной версии. Запасной вариант — `database/schema.sql`: он безопасен для повторного запуска, там только `CREATE TABLE IF NOT EXISTS`.
4. «Система → Очистить кэш».
5. Если у вас nginx, проверьте, что в конфигурации есть `location = /brand.css { rewrite ^ /index.php last; }` (пример в `nginx.conf.example`): без него фирменный цвет не применится.
6. Загляните в `CHANGELOG.md`: там перечислено, что изменилось в вашей версии.

## С 1.3.x на 1.4.0 (cookie-баннер)

Что произойдёт после обновления:

* создастся таблица `cookie_consents` (журнал согласий);
* появятся настройки cookie, баннер **выключен**, поэтому для читателей ничего не изменится;
* появятся два **черновика**: «Политика в отношении cookie» и «Политика обработки персональных данных». Пока вы их не опубликуете, читатели их не видят;
* в админке добавится пункт «Сайт → Cookie и согласия».

Что делать, если аналитики у вас нет: ничего. Если вы собираетесь подключить Яндекс Метрику, пройдите шаги из [docs/COOKIES.md](COOKIES.md).

Если у вас уже стоит счётчик, добавленный вручную в шаблон, уберите его и подключите через настройки. Иначе он будет запускаться без согласия, а CSP заблокирует его запросы.

## С 1.1.x / 1.2.x на 1.3.0

Достаточно заменить файлы и открыть любую страницу. Автоматически произойдёт следующее:

* создадутся таблицы блоков ссылок и страниц разделов; текст «Возврат билетов» и памятка о «Пушкинской карте» перейдут из шаблона «Кино» в редактируемый текст раздела;
* существующие ссылки (Госуслуги, Доставка, соцсети, полезные ссылки) окажутся в блоках с прежними названиями;
* появится таблица `menu_items` с меню по умолчанию (Новости, Афиша, Кино, Погода, Радио, О редакции).

Сделайте вручную:

1. **Погода.** Источник сменился на WeatherAPI.com. В «Настройки → Радио, погода, кино» введите новый ключ: ключ Open-Meteo не подойдёт. Без ключа блок погоды скрыт.
2. Проверьте «Настройки → Сайт и редакция»: заполните падежи города и регион. Если оставить пустыми, они подставятся автоматически, но для редких названий форма может быть неточной.
3. Проверьте версии PHP и СУБД в разделе «Система».

Для читателей изменилось одно: радио продолжает играть при переходах по сайту.
