# Обновление с версии 1.1.x / 1.2.x на 1.3.0

> С 1.2.x достаточно заменить файлы и открыть любую страницу: таблицы блоков ссылок и страниц разделов создаются автоматически (текст «Возврат билетов» и памятка о «Пушкинской карте» переносятся из шаблона «Кино» в редактируемый текст раздела), существующие ссылки (Госуслуги, Доставка, соцсети, полезные ссылки) переносятся в блоки с прежними названиями.

1. **Сделайте резервную копию**: «Система → Создать копию» и копию папки `public/uploads/`.
2. Замените файлы проекта новыми. **Не затирайте** `config/config.php` и `public/uploads/`.
3. Откройте любую страницу сайта. При первом запросе `Migrator` сам создаст таблицу `menu_items` и заполнит меню (Новости, Афиша, Кино, Погода, Радио, О редакции). Вручную SQL выполнять не нужно; запасной вариант — `database/schema.sql` (безопасен для повторного запуска: только `CREATE TABLE IF NOT EXISTS`).
4. **Погода:** источник сменился на WeatherAPI.com. Зайдите в «Настройки → Радио, погода, кино» и введите новый ключ — ключ Open-Meteo не подходит. Без ключа блок погоды скрыт.
5. Проверьте «Настройки → Сайт и редакция»: заполните падежи города и регион (иначе они подставятся автоматически, что для редких названий может дать неточную форму).
6. Очистите кэш: «Система → Очистить кэш».
7. Для nginx добавьте в конфигурацию блок `location = /brand.css { rewrite ^ /index.php last; }` (см. `nginx.conf.example`) — иначе фирменный цвет не применится.
8. Проверьте версии PHP и СУБД в разделе «Система».

Что изменилось для читателей: радио продолжает играть при переходах по сайту (текст на странице «Радио» обновлён).
